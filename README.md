# Surf Condition Evaluator 🏄‍♂️

Un script Node.js simple permettant d'évaluer la qualité et la sécurité des vagues en fonction de leur hauteur.

## Description
Ce projet est une application web (en cours de développement avec **Express.js**) destinée aux passionnés de surf. Elle permet de vérifier rapidement les conditions de session avant de se jeter à l'eau.

## Fonctionnalités principales
- **Évaluation automatique** des vagues selon leur taille.
- **Alertes de sécurité** pour les sessions réservées aux experts.
- API légère développée avec **Node.js** et **Express**.
